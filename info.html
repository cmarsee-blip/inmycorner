About this demo

InMyCorner is a portfolio concept built by Cody Marsee. It is not a live service. This page explains how the demo works.

Privacy

Sign-ups are turned off on this demo, so it doesn't collect personal information. Please don't enter real information anywhere on the site.

Like most websites, loading it involves third parties. Google Fonts and the jsDelivr CDN (for a code library) can see your IP address when they serve files, and GitHub, which hosts the demo, may keep ordinary server logs.

A real version serving children and families would need a privacy policy written and reviewed for that purpose.

Terms

This demo is for illustration only. The athletes, testimonials, stats and matches shown are sample content, and no real people are represented. Nothing here is an offer of service, and there are no accounts, messages or matches.

Design and code by Cody Marsee.

Safety

This demo has no accounts, messaging or matching, so there is nothing to monitor. The site's copy describes how a real version might work, and none of it is built or running here.

A real version serving children would need background checks for mentors, moderated messaging, parental consent, and legal review, designed with people who do that work professionally.
